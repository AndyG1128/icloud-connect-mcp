# Third-party notices and artifact scope

The 55 exact distributions in this inventory comprise 48 runtime dependencies
(8 direct, 40 transitive), 6 test-only dependencies, and 1 build dependency.
Every wheel and sdist was freshly retrieved from PyPI and checksum-verified.
86 retained upstream license/notice/SBOM files were matched to the actual pinned
wheel bytes; supplemental texts remain labelled separately. No dependency was
modified or relicensed. Sources, versions, wheel hashes, exact license expressions
and notice paths are in `docs/dependencies.json` and `notices/manifest.json`.

The authored project source grant is AGPL-3.0-or-later (LICENSE/NOTICE.md),
prepared for the selected source-only Git publication under the owner's conditional
approval. Dependency terms are preserved exactly and are not relicensed. CalDAV's
Apache-2.0 alternative is selected; LGPL/AGPL “or later” declarations remain exact.
Every dependency is acquired separately; no upstream package, stylesheet asset,
native binary, Cargo source archive or tunnel client ships in this source release.
Notice/SBOM metadata and upstream source-access references are included.
No dependency was changed by release preparation; upstream native modifications
are not claimed absent. Native/bundle/hosting questions remain in docs/licensing.md.

The operator may build this project's own package locally. No public wheel,
source tarball, dependency-source bundle or container image is proposed for the
first publication. Public source is the preferred authored form with scripts,
locks, synthetic tests and unchanged original notices. A full combined runtime
network source offer requires the separate checks in docs/source-access.md.
