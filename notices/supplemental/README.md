# Supplemental license texts

GPL-3.0.txt supplies the base GPL terms required alongside retained LGPLv3 terms.
It is the unchanged SPDX license-list-data text from
https://raw.githubusercontent.com/spdx/license-list-data/main/text/GPL-3.0-only.txt .
Its filename identifies the version text; it does not change any dependency's
actual “only” or “or later” grant. LGPL-2.1.txt is supplemental version text, not
evidence of the applicable grant. Exact libiconv 1.18 source headers separately
establish LGPL-2.1-or-later for its library; included command-line/build materials
retain their own terms. Native-source notice files retain unchanged upstream bytes.
