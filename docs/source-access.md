# Source access and operator source offers

## This source release

Public source destination: https://github.com/AndyG1128/icloud-connect-mcp .
The source set includes LICENSE,
NOTICE.md, THIRD_PARTY_NOTICES.md, all original notices, Python preferred source,
pyproject/MANIFEST/locks, scripts, synthetic tests and installation documentation.
Preserve an immutable public commit identifier for every version you distribute
or deploy. Private baseline commit IDs are evidence, not public source URLs.
Record your public source revision with `git rev-parse HEAD` and use that exact
commit in a source URL. If you obtained an unpublished/private copy, do not promise
an accessible public URL until the matching public source actually exists.

Dependencies are not bundled. docs/dependency-source-access.json supplies the
exact 55 separately acquired upstream sdists, versions, license declarations,
direct download URLs and SHA256 values verified during review. Native/source
inventories record collected Cargo/C sources and remaining uncertainties. These
references help obtain/audit sources; a list of links does not itself establish
a complete or permission-cleared network offer. Required notices remain separate
from the authored AGPL grant. No dependency binary/source archive belongs in Git.

## For a modified/covered combined remote deployment

Before representing the network offer as complete, the operator must:

1. Record the exact authored revision, local modifications, dependency versions,
   platform/native artifacts and build configuration of the running instance.
2. Make the preferred project source and any required non-system library/native
   sources, patches, interface definitions and build/install scripts accessible
   at no cost. Preserve their original terms. Do not assume dependencies installed
   by pip or dynamic imports are excluded. Do not expose account configuration,
   passwords, private fixtures, signing keys, ledgers or user data; provide synthetic
   templates instead. Privately held upstream source references are not an offer.
3. Resolve actual-runtime library source scope, including whether unused lxml
   Schematron assets belong to the covered work, and confirm qh3's actual non-FIPS
   feature/content evidence. Obtain upstream permission or qualified review for
   unresolved scope/grants. Do not redistribute the whole uncleared source bundle.
4. Keep equivalent source-copying access for as long as the applicable distribution
   obligations require; if relying on a third-party server, verify its availability
   and exact matching version. Sections 6 and 13 have different triggers; this
   source-only release makes no blanket three-year written-offer commitment.
5. Place a prominent source-offer link in human-facing connection/setup information
   or a visible client message accessible to every remote user. Test visibility and
   the download from each supported client. A repository link in internal operator
   notes or an inaccessible plugin administrator screen is insufficient.

Operator text template, **not a completed offer**:

> Source for this running version, modifications and required dependency/build
> materials is available at no charge at [REVIEWED IMMUTABLE SOURCE URL].
> Authored code: AGPL-3.0-or-later. Dependency terms are preserved separately.

Replace that placeholder only after the matching materials and permissions have
been checked. A client/tunnel readiness test does not verify this source offer.
This project supplies no automatic UI source-offer injection or publisher-hosted
shared service; this documentation/CI update changes no existing plugin/runtime configuration. Operators should get qualified review when scope remains uncertain.
